
# Python Data Processing Project

## Description
Python script to process and clean CSV data, remove duplicates, and generate summary reports.

## Features
- Read CSV files
- Clean data (remove duplicates and missing values)
- Generate summary reports with statistics

## Usage
1. Clone the repository:
```bash
git clone https://github.com/username/python-data-processing.git


2. Install dependencies:
pip install -r requirements.txt

3.  Run the script:
python scripts/process_csv.py
The cleaned data summary report will be saved in reports/summary_report.csv.
